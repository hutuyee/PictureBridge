# 兼容性与限制

## 可预览的内容

PictureBridge 只处理 ShitBot 在 `picturebridge` 模式下发出的 QQ 图片和 QQ 表情。

| 聊天内容 | PictureBridge 行为 |
| --- | --- |
| QQ 图片 | 显示内嵌预览或提供游戏内查看器 |
| QQ 表情 | 显示内嵌预览或提供游戏内查看器 |
| GIF | 在查看器中播放；支持内嵌预览的 Fabric 版本也会在聊天中播放 |
| 普通网页链接 | 保持 Minecraft 原有行为 |
| QQ 语音、视频、文件、分享链接 | 不接管 |
| ShitBot `browser` 模式发出的媒体链接 | 保持 Minecraft 原有行为 |

仅使用 QQ CDN 域名不会触发预览。链接必须带有 ShitBot 添加的 PictureBridge 媒体标记，因此普通玩家发送的网页或图片链接不会被误识别。

## 加载器功能差异

| 加载器 / 版本 | 聊天内嵌预览 | GIF 查看 | 点击后查看原图 | 缩放、拖动、重载、复制链接 |
| --- | --- | --- | --- | --- |
| Fabric 1.14–1.19.4 | — | 查看器中支持 | 支持 | 支持 |
| Fabric 1.20–26.2 | 支持 | 支持 | 支持 | 支持 |
| Forge | — | 查看器中支持 | 支持 | 支持 |
| NeoForge | — | 查看器中支持 | 支持 | 支持 |

Fabric 1.14–1.19.4、Forge 和 NeoForge 不会在聊天记录中插入图片块。它们通过 `[图片]` 或 `[表情]` 标签打开同一个查看器。

## 图片格式

PictureBridge 会识别以下格式：

- PNG
- JPEG
- GIF
- WebP
- BMP

GIF 使用内置的逐帧播放支持。其他格式作为静态图片显示；静态图片最终能否解码，也取决于对应 Minecraft 版本和 JVM 提供的图片解码器。

## 下载限制

| 项目 | 限制 |
| --- | --- |
| URL 协议 | 仅 `http` 和 `https` |
| 重定向 | 最多 5 次，每次都会重新检查目标地址 |
| 下载大小 | 最大 24 MiB |
| 单边尺寸 | 最大 8192 像素 |
| 总像素数 | 最大 3200 万像素 |
| 目标地址 | 拒绝回环、链路本地和局域网地址 |

这些限制同样应用于重定向后的地址。链接返回错误状态、超时、内容不是图片或图片超过限制时，查看器会显示错误信息。

成功下载的图片会暂存在客户端内存中。再次打开同一地址时通常直接使用缓存；点击 `重新加载` 会跳过该缓存并重新下载。离开查看界面后，查看器使用的 GPU 纹理会被释放。

## 与 ShitBot 的配合范围

PictureBridge 可以配合 ShitBot 的 Spigot、BungeeCord 和 Velocity 版本使用。它不需要与 ShitBot 一起构建，也不需要安装到服务端。

ShitBot 的 Nukkit-MOT 版本会发送文本和原始 URL，不使用 PictureBridge 客户端协议。
